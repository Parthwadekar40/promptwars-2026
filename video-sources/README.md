# video-sources

Raw video sources for the site live here. **Drop new videos here** (GitHub → *Add file → Upload files*) or send them in chat.

**Workflow**
1. Originals stay in this folder, untouched — this is the source of truth.
2. Each one gets processed (trim · seamless loop · compress · poster) into `public/assets/video/` and wired into the pages.
3. Need new footage? Upload here directly, or ask me to generate it.

Formats: `.mp4` · `.mov` · `.webm` — any length, any size. I cut what the site needs.
